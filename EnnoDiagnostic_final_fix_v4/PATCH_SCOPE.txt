EnnoDiagnostic Final Fix V4 — portée

1) Verrous
- récupération générique des contraintes explicites de confidentialité/souveraineté/localité dans le corps des documents ;
- le scan transversal n'élève plus tous les passages role=limite en nouveaux verrous ;
- un candidat qui affirme lui-même qu'aucune preuve ne justifie une incertitude est retiré de la liste visible ;
- aucun nom de projet, LLM précis, fichier AI-CODE ou valeur métier n'est codé en dur.

2) Résultats
- le garde de domaine compare la reformulation au corpus du projet courant complet, pas seulement à 2-8 extraits ;
- la consigne exige une reformulation consultant de 2-3 phrases, sans recopier une transcription orale.

3) Frascati / démarche
- conserve la couverture documentaire des cinq critères séparée du score de défendabilité R&D ;
- ingénierie classique bien documentée : 1 % de défendabilité R&D (pas une probabilité administrative) ;
- PydanticAI n'exige plus des maillons techniques sans preuve disponible et n'effectue qu'une réparation maximum.

4) Performance
- cache de reformulation des verrous effectivement câblé dans l'agent ;
- mode rapide des réparations de verrous activé par défaut : pas de cascade retry/final/title LLM ;
- si aucun CIR N-1 n'existe, préflight avant le matching coûteux ;
- les sections ont déjà leur cache V191/V324 ; la version est incrémentée pour ne pas réutiliser les sorties médiocres antérieures.

Non modifié :
- préparation/extraction des sources ;
- nlp_result.json ;
- modèle NLP ;
- RAG/Chroma ;
- documents bruts ;
- données Memory V2.
