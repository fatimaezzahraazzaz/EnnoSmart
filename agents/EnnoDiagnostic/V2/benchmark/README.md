# Benchmark de validation

Prépare environ 10 dossiers connus :
- RAW avec verrous implicites ;
- document avec verrous explicites ;
- CIR structuré ;
- plusieurs documents pour le même projet ;
- dossier sans vrai verrou ;
- dossier riche en méthodes/résultats.

Pour chaque dossier, annote manuellement :
- objectifs ;
- verrous ;
- méthodes ;
- résultats ;
- paramètres ;
- preuve exacte.

Mesure au minimum :
- rappel des verrous ;
- précision des verrous ;
- faux verrous ;
- preuves inventées ;
- qualité de fusion inter-documents ;
- rappel objectifs / méthodes / résultats / paramètres.

Ne décide pas sur un seul test.
La V2 remplace la V1 seulement lorsqu'elle est meilleure sur l'ensemble du benchmark.
